## Cross-cutting unresolved acceptance evidence

- YOLOX-S ONNX and CPU ONNX Runtime are installed in `.venv`; actual detections/tracks/counts are
  verified on a CC BY 3.0 recording and through a localhost replay/API/DB/React test. No GPU driver.
- The Commons clip and YOLOX weights are locally downloaded with approval and checksums recorded;
  no large media/model files are committed.
- Ultralytics is not used by the inference runtime. The owner selected the permissive YOLOX path
  while keeping RoadSentinel private; broader repository/dependency licensing still needs review.
- No authorized external Romanian source is known. Candidate viewing pages remain disabled and
  do not establish analytics, recording, retention or redistribution permission.
- A live local replay → YOLOX overlay → HMAC FastAPI → PostgreSQL → authenticated React camera-detail
  run used real model output. The final catalog-inclusive E2E asserted changing frames, counts and
  26 read-only candidate entries; the replay generated no model incident event. See
  `docs/END_TO_END_DEMO_EVIDENCE.md`.
- Current host GPU probe reports NVIDIA-SMI cannot communicate with a driver; CPU is the only
  evidenced execution target. RAM at probe: 23 GiB total, 6.9 GiB available; disk free: 73 GiB.
- Docker CLI is available, but its Unix socket API remains denied even though this process reports the socket's GID in its group list. This execution context cannot establish whether the user's normal terminal can access Docker; no host permissions changed.
